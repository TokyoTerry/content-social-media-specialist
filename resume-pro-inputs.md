## REFERENCE: T's RESUME STANDARDS (For Consistency with Client Work)

*Use these same standards when building client resumes:*

- **Font:** 12px throughout all sections
- **Education Dates:** Single-line format — *Degree, University, start date – end date*
- **White-Text Dates (optional):** `.job-period { color: #ffffff; }` to hide sensitive dates if client requests
- **No Graphics/Embeds:** Plain text only (ATS-friendly)
- **Keywords:** Match job posting language in skills/experience descriptions
- **Quantification:** Prefer "Led 5-person team" over "Led team"; "Increased revenue 23%" over "Strong sales results"
- **Tone:** Professional, past-tense for previous roles; present-tense for current role
- **No Jargon Fluff:** Avoid buzzwords like "synergy," "leveraging," "thought leader" unless specifically relevant
